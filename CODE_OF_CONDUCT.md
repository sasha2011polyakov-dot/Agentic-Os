# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and kind. Disagree with ideas, not with people.
- Welcome newcomers. Every question is fine.
- No harassment, insults, discrimination, sexualized content or personal attacks — in issues, pull requests, reviews, discussions or any other project space.
- Do not publish other people's private information.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers privately. Use the contact on the maintainer's GitHub profile ([@sasha2011polyakov-dot](https://github.com/sasha2011polyakov-dot)). Reports are handled confidentially.

Maintainers may remove comments, commits, code, issues and other contributions that violate this code. They may also block participants, temporarily or permanently, according to the enforcement guidelines of the Contributor Covenant.
