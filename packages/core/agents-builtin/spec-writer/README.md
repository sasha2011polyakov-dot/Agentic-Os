# Генератор технического задания

Пишет повествовательные разделы ТЗ на основе требований, задач и свидетельств.

- Тип задачи для маршрутизации моделей: `generation`
- Инструменты: нет (работает только с переданными данными)

## Запрашиваемые разрешения
- не требуются

Вход и выход описаны JSON-схемами в папке `schemas/`. Пакет не содержит исполняемого кода.
