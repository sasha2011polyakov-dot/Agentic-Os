# Консультант поручения

Отвечает на вопросы пользователя о ходе поручения и предлагает корректировки.

- Тип задачи для маршрутизации моделей: `chat`
- Инструменты: нет (работает только с переданными данными)

## Запрашиваемые разрешения
- не требуются

Вход и выход описаны JSON-схемами в папке `schemas/`. Пакет не содержит исполняемого кода.
